# antislop audit 001 (2026-11-17)

Mode: AFTER (session override). Scope: the Studio web app as deployed on 2026-11-17 (Dashboard, Insights, Create,
episode page, Accounts, Login, legal pages, app manifest). Nothing has been changed yet: pick the numbers to fix.

Evidence was gathered by code inspection plus a measured run on an iPhone 14 viewport (production build, local
database): tap-target sizes, computed cursor, focus styles, horizontal overflow, document titles, console errors
(0 errors), and a WCAG contrast calculation for every text/background color pair in `globals.css`.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## HIGH (Hard Gate)

| # | Rule | Finding |
|---|---|---|
| 1 | R-37 | The UI was built without design direction (no `DESIGN.md`). The indigo accent and generic dashboard look have no link to the Uco Ocu brand kit (orange/teal duo, comic origin). |
| 2 | R-23 | The app name "Studio" and the purple "S" icon were invented without your confirmation. They appear in the login screen, tab title, home-screen icon and the TikTok/Meta/Google app listings. |
| 3 | R-39 | Buttons show the default arrow cursor instead of a pointer (measured: "Run Analyst", "Pitch me 5 ideas", "Remove demo data"); disabled buttons don't show `not-allowed`. Cause: Tailwind v4 base styles. |
| 4 | R-39 | Form fields have no visible label, only placeholder text: the Create direction box, the script revision box, and the login password field. |
| 5 | R-32 | Weak focus indicator: text fields remove the outline (`outline-none`) and only change a 1px border color; buttons and links rely on the browser default ring, so keyboard focus is inconsistent and hard to see. |
| 6 | R-39 | Loading skeletons pulse indefinitely and ignore `prefers-reduced-motion`. |
| 7 | R-39 | Every page has the same tab title "Studio" (Dashboard, Insights, Create, Accounts, each episode). Titles must be unique per page. |
| 8 | R-39 | Most buttons, chips and nav items have no distinct hover and active (pressed) state; only 3 hover styles exist in the codebase. |
| 9 | R-03 | Tap targets under 44px on phones: 7 of 11 controls on the Dashboard (filter chips are 30px tall), "Run Analyst" and "Pitch me 5 ideas" (36px), "Remove demo data" (30px), per-account "Remove" and "Copy" buttons (about 24px). |
| 10 | R-25 | Contrast below 4.5:1 in light mode: Uco's orange name on his tinted bubble (3.9:1) and Ocu's teal name on his bubble (3.8:1), at an 11px size. All other color pairs pass (dark mode passes everywhere). |
| 11 | R-27 | Missing empty states: the weekly views chart draws an empty frame with no message when there are no posts, and the Dashboard shows zeros and dashes with no hint to connect accounts or publish a first episode (your situation right now). |
| 12 | R-02 | Em dash in visible text: the installed-app name "Studio — Content Platform" in the web app manifest. |

- R-24, R-26: every nav item leads to a real page; no dead buttons (the unbuilt features are labeled "Later phase" or explained).
- R-03 (layout): no horizontal overflow on any page at phone width.
- R-34: both light and dark themes render correctly.
- R-15, R-16: buttons say what they do ("Pitch me 5 ideas", "Run Analyst"); no marketing buzzwords.
